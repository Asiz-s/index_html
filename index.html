미적분Ⅰ: 변화율·누적량을 이용한 실제 데이터 모델 비교

주민등록 인구 월간 CSV를 이용해 선형·지수·로지스틱 모델을 비교합니다. 앱은 최적 모델을 자동으로 결정하지 않습니다.

1. 데이터 입력

CSV를 업로드하세요.

2. 분석 설정

현재 CSV 구조에서는 행정구역 행을 선택하고 각 월의 총인구수 열을 자동 추출합니다.

3. 실제 인구와 모델 비교

4. 변화율 분석

실제 데이터의 구간 변화율: (Pi+1 − Pi) / (ti+1 − ti)

5. 오차 비교

6. 모델의 수학적 의미

선형

P(t)=at+b
P′(t)=a

일정한 변화율을 가정합니다.

지수

P(t)=Aekt
P′(t)=kAekt

현재 크기에 비례하는 변화율을 가정합니다.

로지스틱

P(t)=K/(1+Ae−kt)
P′(t)=kP(t)(1−P(t)/K)

성장 한계 K에 가까워질수록 변화율이 줄어드는 모델입니다.
